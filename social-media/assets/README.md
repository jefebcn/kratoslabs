# Assets social — carica qui le immagini

Cartella dove caricare i materiali per produrre i post (vedi `../asset-brief.md`).

## Come caricare da GitHub (senza usare comandi)

1. Vai su questa cartella nel branch **`claude/social-media-posts-instagram-tiktok-56jx8c`**
2. Bottone **Add file → Upload files**
3. Trascina le immagini/video
4. In fondo, lascia selezionato **"Commit directly to the … branch"** e conferma

Appena caricate, avvisami qui: le prendo e parto con i post grafici.
